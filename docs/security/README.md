# Security baseline

Living security records for EditAgent. US-108 is version 0. Later security tests should cite the IDs in these documents rather than inventing new names for the same threat.

| Document                             | What it holds                                                             |
| ------------------------------------ | ------------------------------------------------------------------------- |
| [risk-register.md](risk-register.md) | Technical, schedule, and cost risks with an owner role and a mitigation   |
| [threat-model.md](threat-model.md)   | STRIDE analysis of the accepted container diagram, with stable threat IDs |

The architecture decisions in [../architecture/adr](../architecture/adr/README.md) stay accepted. These pages do not change them. A control listed here is planned backlog work unless the threat record says a slice of it already exists.

Owners are roles and lanes. No personal names are assigned until the team has real assignees.
