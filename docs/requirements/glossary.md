# Domain glossary

Ubiquitous language for US-102. The twelve names in the canonical table are fixed spellings. US-104 must use those spellings as domain type names. US-104 is not implemented in this pull request, so US-102 AC2 is not fully verified yet. This glossary is the contract that verification will check.

Architecture modules and accepted ADR-001 through ADR-008 decide ownership and technology. A glossary entry does not move a feature into the MVP. Scope for each capability is in the [SRS](srs.md).

## Canonical names

These strings are the names US-104 must use. Do not rename them in code, schemas, or later requirements.

| Name           | Definition                                                                                                                                                                                                                                                                                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MediaAsset     | One stored source medium owned by a Project: a video, an audio recording, or an image. It has a MediaAssetId, technical metadata, and an object-storage key. The bytes are not a PostgreSQL column (ADR-005). Video, Audio, and Image are subtypes to be modeled in US-104. A proxy, thumbnail, or extracted audio track is not a MediaAsset; it is a DerivedAsset. |
| Project        | The root aggregate a Creator works in. It owns membership, the selected platform preset, the target duration, its MediaAssets, its Timelines, its AgentRuns, and its renders. Archiving a Project hides it from the default list and does not delete object-storage bytes by itself.                                                                                |
| Timeline       | The ordered composition for one edit of a Project. It contains Tracks. Every placement on a Timeline is an integer number of microseconds from the start of that Timeline (ADR-008). A Project may keep more than one Timeline when version history stores a prior composition.                                                                                     |
| Track          | One lane of a Timeline. The MVP lanes are video, audio, caption, and overlay. A Track holds Clips in timeline order and does not itself store media bytes.                                                                                                                                                                                                          |
| Clip           | A placement on a Track. It refers either to a half-open range of a MediaAsset or to a generated segment, with an in-point and an out-point in integer microseconds. A Clip is not a file.                                                                                                                                                                           |
| Effect         | A parameterized visual or audio treatment attached to a Clip or to a Timeline range. Loudness ducking, reframing, and a zoom are Effects. An Effect is not a Tool. A Tool may create or change an Effect. When the treatment is drawn by Remotion, the Effect refers to a Component and a props value that validates against that Component's schema.               |
| Tool           | A registered operation the AI Agent or a deterministic workflow may call. Its manifest names the argument schema, the permissions it may use, a cost, and a timeout. No Tool declares a shell permission. The FFmpeg argument vector for a Tool is built only in `packages/media-core` once that story exists (ADR-001, layer rules).                               |
| Component      | A Remotion visual unit registered with a ComponentManifest: a props schema and a trust level. Captions, titles, transitions, and zoom treatments that are drawn rather than filtered are Components. A Component is not a React page in `apps/web`.                                                                                                                 |
| AgentRun       | One execution of the observe-plan-act loop for a Project. It has a lifecycle, a prompt reference, ordered events, and tool calls that were validated against JSON Schema before they ran (ADR-003, ADR-006). It is not a Job, though Jobs may carry its steps.                                                                                                      |
| Critique       | The structured result of reviewing one render: the checks that failed, the evidence, and whether a refinement was requested. The Critic module owns it. A Critique does not mutate a Timeline. An AgentRun or an Editing command may do that afterward.                                                                                                             |
| BrandKit       | Project-scoped creative settings: colors, font references, and logo references. Projects owns the record. Applying a BrandKit during an edit is Advanced (US-521). The type is named here so US-104 can introduce it without renaming it later.                                                                                                                     |
| CreativeMemory | Project-scoped record of creative choices the agent must reuse inside that Project, such as a chosen caption style or refrain from a prior AgentRun. The Agent module owns it (US-409). It is not a BrandKit.                                                                                                                                                       |

## Related terms

These names are not in the US-102 mandatory list. They are included so later stories do not invent a second word for the same idea. US-104 may use them as type names. If it does, it must use the spelling in this table.

| Name           | Definition                                                                                                                                                                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| User           | An account that can authenticate. Identity owns it. A User is not a Project member until a membership row exists.                                                                                                                                       |
| Role           | One of Owner, Editor, Viewer, or Admin. Owner, Editor, and Viewer are Project membership roles. Admin is an operator role and is not implied by membership.                                                                                             |
| Session        | The authenticated period of a User after sign-in, including expiring tokens. Identity owns it.                                                                                                                                                          |
| DerivedAsset   | A product of a MediaAsset: proxy, thumbnail, or extracted audio. Media owns it. It is addressable in object storage and is not a second MediaAsset.                                                                                                     |
| MediaAnalysis  | The versioned perception document for one MediaAsset: transcript, speech segments, silence, loudness, and optional shots and faces. Analysis owns it. The cross-language form is a JSON Schema (ADR-003), not a hand-copied TypeScript and Python pair. |
| EditCommand    | One reversible change to a Timeline. Editing owns the command log. Replay is defined on integer microseconds, not on formatted timecode strings (ADR-008).                                                                                              |
| Job            | One asynchronous unit of work with a state machine and progress events. Jobs owns the Job. The module that does the work owns the result. A Job is not an AgentRun and not a MediaAsset.                                                                |
| RenderProfile  | Preview or final settings for one render. Rendering owns it. The MVP final profile is H.264/AAC MP4 at or below 1080p.                                                                                                                                  |
| PlatformPreset | Named output rules for a target platform: frame size, aspect ratio, duration cap, safe-zone insets, and loudness. Projects stores the preset selected on a Project. The legal names and numbers are in the SRS.                                         |
| SafeZone       | The axis-aligned rectangle, as percentages of frame width and height, inside which captions and titles must lie for a PlatformPreset.                                                                                                                   |
| Prompt         | The natural-language instruction that starts or revises an AgentRun. The Agent module stores it through the versioned prompt registry. A Prompt is not a Tool argument until the agent emits a validated call.                                          |

## Verification of US-102 AC2

The canonical names above are the contract. Full verification is: when US-104 adds the domain model, each canonical name appears as a type name with that exact spelling. This pull request does not add those types and does not mark AC2 verified.
